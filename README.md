# Finance Notes｜金融知識筆記

一個可以持續延伸的繁體中文金融入門知識網站。具備首頁、分類頁和獨立文章頁。

## 如何預覽
解壓縮後雙擊 `index.html`，或上傳完整檔案至 GitHub Pages。

## 網站內容
- 首頁：知識分類與文章入口
- 分類頁：總體經濟、貨幣政策、債券市場
- 文章頁：GDP、CPI、利率、債券殖利率

## 如何讓 AI 新增內容
請 AI 先閱讀 `AGENTS.md`，再說：「請依照 AGENTS.md 新增『匯率是什麼？』文章，並更新對應分類與首頁入口。」

## GitHub Pages
建立 Public repository，上傳**這個資料夾內的所有檔案和子資料夾**，在 Settings → Pages 選擇 Deploy from a branch、main、/(root)。

本網站內容僅供一般金融教育，不構成投資建議。
